## ساختار پروژه

```
divar-ml-project/
├── README.md              ← همین فایل (نقشه و قوانین پروژه)
├── .gitignore             ← جلوگیری از آپلود فایل‌های دیتا
├── requirements.txt       ← کتابخونه‌های موردنیاز
├── utils.py               ← توابع مشترک (UTM، تاریخ شمسی، قیمت هدف)
└── notebooks/
    ├── 01_preprocessing.ipynb      ← آماده‌سازی و تمیزکاری داده
    ├── 02_descriptive_stats.ipynb  ← آمار توصیفی (سؤال ۱ تا ۹)
    ├── 03_hypothesis_tests.ipynb   ← آزمون فرض (۴ فرضیه)
    ├── 04_clustering.ipynb         ← خوشه‌بندی / توصیه‌گر (مسئله ۱)
    └── 05_prediction.ipynb         ← پیش‌بینی قیمت (مسئله ۲)
```

## دیتا

فایل‌های دیتا روی گیت‌هاب نیستند و نباید آپلود شوند. دیتاست روی Google Drive مشترک تیم نگه‌داری می‌شود و از طریق Colab لود می‌شود. خروجی دیتای تمیزشده هم روی همان Drive ذخیره می‌شود.

## قوانین کار تیمی

- هر کس فقط روی نوت‌بوک فاز خودش کار می‌کند؛ همزمان دو نفر روی یک فایل کار نمی‌کنند.
- قبل از شروع کار، همیشه آخرین نسخه‌ی فایل را از گیت‌هاب باز کنید (نه نسخه‌ی قدیمی).
- بعد از اتمام کار، با پیام واضح کامیت بزنید (مثلاً «سؤال ۳ آمار توصیفی اضافه شد»).
- کامیت‌های کوچک و مکرر بهتر از یک کامیت بزرگ آخر کار است.
- در مسیر و اسم فایل‌ها هیچ فاصله‌ای نگذارید.
