## دسترسی به دیتا

قبل از شروع کار، هر عضو تیم باید یک‌بار این کار را انجام دهد:

۱. لینک پوشه‌ی دیتا (موجود در داکیومنت توضیحات پروژه) را با جیمیل خودت باز کن.
